# Security Policy

## Reporting a Vulnerability

**Email:** security@imperialarchive.ai

**Please DO NOT:**
- Open a public issue
- Disclose publicly
- Exploit the vulnerability

**Please DO:**
- Send an email with details
- Include reproduction steps
- Allow 48 hours for response

- Repository: latifah6114-ux/Imperial-Archive
- Domain: imperialarchive.ai

Only the `main` branch is supported.
