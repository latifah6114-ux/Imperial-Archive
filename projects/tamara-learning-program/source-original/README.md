# Tamara Learning Program source intake

This folder preserves the file names and classifications supplied for the project. The project is governed by the Imperial Archive educational master and the fixed identity/growth standard.

## Rules

- Preserve originals.
- Build canonical outputs around originals.
- Never overwrite release history.
- Keep identity, cover, closing page, ownership, seal, and signature locked.
- Version content, profiles, weekly packages, and daily patches additively.
- Do not invent missing assets or curriculum.

## Repository placement

- `projects/tamara-learning-program/source-original/` — immutable source evidence
- `projects/tamara-learning-program/canonical/` — derived implementation
- `projects/tamara-learning-program/assets/` — verified assets only
- `projects/tamara-learning-program/audio/` — archived audio masters and manifests
- `projects/tamara-learning-program/manifests/` — machine-readable project records
- `projects/tamara-learning-program/reports/` — QA, gap, provenance, and rights reports
- `projects/tamara-learning-program/releases/` — versioned release candidates and locked releases
